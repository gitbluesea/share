# 점을 보는 AI vs. 종이를 보는 인간
  
1. 데이터 출생신고서
- 누가 만들었는가
- 왜 만들었는가
- 왜 하필 지금인가

2. 두 칸 노트 작성
- 현재 변하고 있는 것(수단) vs.  5년 뒤에도 변하지 않을 것(목적)
- 목적에 조금 더 많은 자원 배분

3. 맥락 배달 경로 점검
- 현장의 목소리가 의사결정자에게 도달하는 시간
- "콜센터 일지 작성 -> 주간 보고로 요약 -> 회의 안건으로 상정" 하는 동안 맥락 증발
